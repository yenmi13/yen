gmail-cleanup 隱私權政策

最後更新：2026-09-26

gmail-cleanup 是網站作者自用的信箱整理工具，只在作者本人的電腦上執行，只存取作者本人授權的 Gmail 帳號，不對外提供服務，也不開放其他使用者登入。

存取哪些資料

工具透過 Gmail API 讀取收件匣信件的寄件者、主旨、摘要片段與標籤，用來判斷信件分類；並依分類結果貼標籤、封存或移至垃圾桶。工具不讀取附件，也不寄出任何郵件。

資料如何處理

  • OAuth 憑證只存在作者本機，不上傳到任何伺服器。
  • 分類時僅送出去識別化的寄件網域、主旨與摘要片段（已移除 email、電話與網址）至文字分類 API，不送出信件全文。
  • 不販售、不分享、不用於廣告，也不用於訓練任何模型。
  • 整理紀錄只保存在作者本機，可隨時刪除。

Google API 使用聲明

本工具對 Google API 取得之資料的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

撤銷授權

可隨時於 Google 帳戶「安全性 → 第三方存取權」撤銷本工具的存取權限。
